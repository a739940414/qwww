# نظام Alatabe Soft – النظام المحاسبي المتكامل

## 🧭 الهدف العام

يهدف نظام **Alatabe Soft** إلى توفير منصة محاسبية وإدارية متكاملة للشركات الصغيرة والمتوسطة، مع دعم كامل لتعدد العملات والفروع وتوليد القيود المحاسبية تلقائيًا من جميع العمليات المالية.

## 🧩 الوحدات الرئيسية

| الوحدة | الوظائف الأساسية |
| --- | --- |
| 🧾 الحسابات العامة (General Ledger) | دليل حسابات شجري، قيود يومية، ميزان مراجعة، دفتر الأستاذ، القوائم المالية |
| 💱 العملات وأسعار الصرف | إنشاء حركات وفواتير بأي عملة، سعر صرف يدوي أو تلقائي، فروقات عملات |
| 💰 الصناديق والبنوك | إدارة الصناديق والبنوك، سندات قبض وصرف، تحويلات، مطابقة بنكية |
| 🧍 العملاء والموردين | إدارة الذمم المدينة والدائنة، فواتير بيع وشراء، كشوف حسابات |
| 📦 المخزون المتكامل | بطاقة صنف، وحدات، تنبيهات حد أدنى، الجرد الدوري، حركة الأصناف |
| 🧮 القيود التلقائية | توليد قيود آلية من جميع العمليات المالية |
| 🏢 مراكز التكلفة والفروع والمشاريع | تحليل الأداء المالي حسب الفرع أو المركز أو المشروع |
| 🧑‍💼 المستخدمون والصلاحيات | إنشاء مستخدمين بأدوار محددة وصلاحيات دقيقة |
| 📈 التقارير والتحليل المالي | رسومات بيانية، تقارير مالية وإدارية، تصدير إلى PDF/Excel |
| 🔐 الأمان والنسخ الاحتياطي | تشفير البيانات، نسخ احتياطي واستعادة تلقائية |
| 🌐 دعم اللغة العربية والإنجليزية | RTL كامل، إمكانية التبديل بين اللغتين |
| ⚙️ مرونة التوسعة المستقبلية | دعم الحقول الإضافية، التكامل مع الأنظمة المستقبلية |

## 🧱 تصميم قاعدة البيانات

### Accounts (دليل الحسابات)
- **AccountID** (INT): المفتاح الأساسي.
- **ParentID** (INT, NULL): الحساب الأب.
- **Code** (NVARCHAR(20)): كود الحساب.
- **Name** (NVARCHAR(100)): اسم الحساب.
- **Type** (NVARCHAR(20)): نوع الحساب (أصل، خصم، مصروف...).
- **CurrencyID** (INT): العملة الافتراضية.
- **BranchID** (INT): الفرع.
- **CostCenterID** (INT): مركز التكلفة الافتراضي.
- **IsActive** (BIT): هل الحساب نشط؟
- **CustomFields** (NVARCHAR(MAX)): بيانات إضافية بصيغة JSON.

### Currencies (العملات)
- **CurrencyID** (INT): المفتاح.
- **Code** (NVARCHAR(10)): رمز العملة (USD, SAR, EUR...).
- **Name** (NVARCHAR(50)): اسم العملة.
- **Symbol** (NVARCHAR(5)): رمز العملة.
- **ExchangeRate** (DECIMAL(18,6)): سعر الصرف الحالي.
- **IsBaseCurrency** (BIT): هل هي العملة الأساسية؟
- **LastUpdated** (DATETIME): آخر تحديث للسعر.

### CashBoxes (الصناديق)
- **CashBoxID** (INT): المفتاح.
- **Name** (NVARCHAR(100)): اسم الصندوق.
- **CurrencyID** (INT): العملة.
- **Balance** (DECIMAL(18,6)): الرصيد الحالي.
- **BranchID** (INT): الفرع.
- **ResponsibleUser** (INT): المستخدم المسؤول.

### Banks
- **BankID** (INT): المفتاح.
- **Name** (NVARCHAR(100)): اسم البنك.
- **AccountNumber** (NVARCHAR(30)): رقم الحساب البنكي.
- **CurrencyID** (INT): العملة.
- **Balance** (DECIMAL(18,6)): الرصيد.
- **BranchID** (INT): الفرع.

### CashReceipts (سندات القبض)
- **ReceiptID** (INT): رقم السند.
- **Date** (DATETIME): التاريخ.
- **CashBoxID** (INT): الصندوق.
- **CurrencyID** (INT): العملة.
- **Amount** (DECIMAL(18,6)): المبلغ.
- **ExchangeRate** (DECIMAL(18,6)): سعر الصرف.
- **CustomerID** (INT): العميل.
- **Description** (NVARCHAR(255)): البيان.
- **EntryID** (INT): رقم القيد التلقائي.
- **CreatedBy** (INT): المستخدم.

> **القيد التلقائي:** من ح/ الصندوق إلى ح/ العميل.

### CashPayments (سندات الصرف)
- **PaymentID** (INT): رقم السند.
- **Date** (DATETIME): التاريخ.
- **CashBoxID** (INT): الصندوق.
- **CurrencyID** (INT): العملة.
- **Amount** (DECIMAL(18,6)): المبلغ.
- **ExchangeRate** (DECIMAL(18,6)): سعر الصرف.
- **ExpenseAccountID** (INT): حساب المصروف أو المورد.
- **Description** (NVARCHAR(255)): البيان.
- **EntryID** (INT): رقم القيد التلقائي.
- **CreatedBy** (INT): المستخدم.

> **القيد التلقائي:** من ح/ المصروف إلى ح/ الصندوق.

### JournalEntries / JournalDetails
- **EntryID**، **Date**، **CurrencyID**، **ExchangeRate**، **Description**، مع تفاصيل الحسابات والمبالغ والمراكز والفروع.

### Customers / Suppliers
- **EntityID** (INT): المفتاح.
- **Type** (NVARCHAR(10)): "Customer" أو "Supplier".
- **Name** (NVARCHAR(100)): الاسم.
- **Phone** (NVARCHAR(20)): رقم الهاتف.
- **Email** (NVARCHAR(100)): البريد الإلكتروني.
- **Address** (NVARCHAR(200)): العنوان.
- **CurrencyID** (INT): العملة الافتراضية.
- **CreditLimit** (DECIMAL(18,6)): حد الائتمان.
- **Balance** (DECIMAL(18,6)): الرصيد الحالي.

### Invoices
- **InvoiceID** (INT): رقم الفاتورة.
- **Date** (DATETIME): التاريخ.
- **Type** (NVARCHAR(10)): "Sale" أو "Purchase".
- **CustomerID / SupplierID** (INT): العميل أو المورد.
- **CurrencyID** (INT): العملة.
- **ExchangeRate** (DECIMAL(18,6)): سعر الصرف.
- **Total** (DECIMAL(18,6)): الإجمالي.
- **Tax** (DECIMAL(18,6)): الضريبة.
- **Discount** (DECIMAL(18,6)): الخصم.
- **Status** (NVARCHAR(20)): الحالة (مسددة، جزئية، مفتوحة).
- **EntryID** (INT): رقم القيد التلقائي.

### Inventory
- **ItemID** (INT): رقم الصنف.
- **Code** (NVARCHAR(20)): الكود.
- **Name** (NVARCHAR(100)): الاسم.
- **Unit** (NVARCHAR(20)): الوحدة.
- **MinQty** (DECIMAL(18,6)): الحد الأدنى.
- **Cost** (DECIMAL(18,6)): تكلفة الشراء.
- **SalePrice** (DECIMAL(18,6)): سعر البيع.
- **CurrentQty** (DECIMAL(18,6)): الرصيد الحالي.

### جداول تحليلية
جداول **CostCenters** و**Branches** و**Projects** لربطها بجميع العمليات وتحليل الأداء المالي التفصيلي.

## 💱 نظام العملات

- دعم التعامل بعملات متعددة لكل حساب أو عملية.
- إدخال سعر الصرف يدويًا أو اقتراحه من جدول الأسعار.
- تسجيل فروقات الصرف في حساب مخصص.
- إمكانية توليد التقارير بأي عملة يختارها المستخدم.

## 🧾 القيود التلقائية

| العملية | القيد التلقائي |
| --- | --- |
| فاتورة بيع | من ح/ العميل إلى ح/ المبيعات |
| فاتورة شراء | من ح/ المشتريات إلى ح/ المورد |
| سند قبض | من ح/ الصندوق إلى ح/ العميل |
| سند صرف | من ح/ المصروف إلى ح/ الصندوق |
| تحويل بين الصناديق | من ح/ الصندوق (المحول منه) إلى ح/ الصندوق (المحول إليه) |
| جرد المخزون | من ح/ خسائر الجرد إلى ح/ المخزون (أو العكس) |

## 📈 التقارير والتحليل

- دفتر أستاذ، ميزان مراجعة، قائمة دخل، مركز مالي.
- كشوف حسابات العملاء والموردين، كشف الصندوق والبنك.
- تقارير الفروع ومراكز التكلفة وتحليل المبيعات والمشتريات وفروقات العملات.
- لوحات معلومات تفاعلية ورسومات بيانية مع دعم التصدير إلى PDF/Excel/CSV.

## 🧑‍💼 إدارة المستخدمين والصلاحيات

- نظام صلاحيات دقيق على مستوى العمليات والتقارير.
- حظر التعديل أو الحذف بعد الاعتماد.
- سجل نشاط المستخدمين (Audit Log).
- ربط المستخدم بفرع محدد.

## 🔐 الأمان والنسخ الاحتياطي

- تشفير البيانات باستخدام AES-256.
- نسخ احتياطي تلقائي يومي أو أسبوعي مع استعادة سهلة.
- قفل تلقائي عند الخمول ودعم مستقبلي للتحقق بخطوتين.

## 🌐 واجهة المستخدم (UI)

- واجهة WPF حديثة تدعم اللغة العربية (RTL) بالكامل مع إمكانية التبديل إلى الإنجليزية.
- شاشة رئيسية تتضمن Dashboard للمؤشرات الحيوية مثل الرصيد الإجمالي، النقد المتاح، مبيعات اليوم، المصروفات، حالة الصناديق والبنوك.
- قوائم منظمة: الرئيسية، الحسابات، الصناديق، البنوك، القيود، التقارير، الإعدادات.

## ⚙️ التقنيات المقترحة

- **اللغة:** C# .NET 8
- **واجهة المستخدم:** WPF (Material Design)
- **قاعدة البيانات:** SQL Server LocalDB أو SQLite
- **ORM:** Entity Framework Core
- **التقارير:** RDLC أو FastReport
- **التصدير:** iTextSharp، EPPlus

## ✅ الخلاصة

يمثل نظام **Alatabe Soft** حلًا محاسبيًا متكاملًا يجمع بين المرونة والدقة وسهولة الاستخدام، ويغطي جميع الجوانب المالية من الصناديق والبنوك إلى المخزون والعملاء والموردين، مع دعم كامل لتعدد العملات والفروع ومراكز التكلفة وتوليد القيود المحاسبية آليًا.

## 🏗️ بنية المشروع (Project Structure)

تم إنشاء حل أولي بلغة **C# .NET 8** وفق نمط متعدد الطبقات لتسهيل التطوير المستقبلي:

```
AlatabeSoft.sln
└── src
    ├── AlatabeSoft.Domain           ← الكيانات (Entities) والتعدادات وقيم المجال
    ├── AlatabeSoft.Application      ← عقود الخدمات (Interfaces) وكائنات النقل (DTOs)
    ├── AlatabeSoft.Infrastructure   ← DbContext وإعدادات Entity Framework وخدمات البنية التحتية
    └── AlatabeSoft.Presentation.Wpf ← تطبيق WPF بواجهة عربية ولوحة معلومات أولية
```

### 📦 الطبقة Domain
- نماذج شاملة للحسابات، العملات، الصناديق، الفواتير، المخزون، المستخدمين، القيود اليومية وغيرها.
- قيم مجال مثل `AccountType` و`JournalEntrySource` لتوحيد أنواع البيانات داخل النظام.

### 🧠 الطبقة Application
- تعريف عقود الخدمات الرئيسية مثل `ICurrencyService` و`IJournalEntryService` و`IAccountsService`.
- كائنات نقل بيانات (DTOs) تدعم بناء واجهات المستخدم وواجهات البرمجة مستقبلًا.

### 🛠️ الطبقة Infrastructure
- `AlatabeSoftDbContext` مع تكوينات جداول مفصلة تتوافق مع تصميم قاعدة البيانات الوارد في المواصفات.
- خدمات تنفيذية تعتمد على EF Core مثل `CurrencyService` و`JournalEntryService` لتنفيذ العمليات المحاسبية التلقائية.
- ملف `DependencyInjection` لتجهيز الحاوية (DI Container) وربط الخدمات بسهولة.

### 🖥️ طبقة العرض WPF
- واجهة RTL حديثة تعرض لوحة معلومات عربية مع بطاقات إحصائية وتنبيهات المخزون وقائمة تنقل للوحدات.
- قوالب ألوان وأنماط مخصصة لتجربة استخدام متناسقة، مع ViewModel يوفر بيانات تجريبية لحين ربط الخدمات الفعلية.

> 🚀 هذه البنية تمهد الطريق لإضافة الخدمات المتقدمة (التقارير، الترحيل، التكامل) بشكل تدريجي دون التضحية بقابلية الصيانة.
